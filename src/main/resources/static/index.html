Truth tables

Type a formula and see every case at once. This page is the front end for the code you are writing in Operators.java and LogicAnalyzer.java — if a column looks wrong, the bug is in your Java, not here.

Are two formulas equivalent?

You can type operators three ways — symbols, ASCII, or words.

¬~ ! not — negation
∧& && and — conjunction
∨| || or — disjunction
⊕^ xor — exclusive or
→-> => implies — implication
↔<-> <=> iff — biconditional

Binding order, loosest to tightest: ↔, →, ⊕, ∨, ∧, ¬. Implication groups to the right, so p -> q -> r means p -> (q -> r). Use parentheses when in doubt.
